# AGENTS.md

## О проекте
Этот репозиторий содержит CLI инструмент `lit` для управления задачами. Основной стек: Python 3.11+, Docker.

## Быстрый старт
- Установка зависимостей: `pip install -r requirements.txt` (или используйте `poetry`)
- Запуск тестов: `pytest`
- Линтинг: `ruff check . --line-length 88`

## Ключевые соглашения
- **Коммиты**: Используется Conventional Commits. Подробная инструкция — в скилле `.agents/skills/git-commit-convention/SKILL.md`.
- **Ветки**: `master` — стабильная, `dev` — для разработки. Фичи — в `feature/*`.
- **Релизы**: Автоматизированы через `release-please`.

## Архитектура (кратко)
- `*.py` — исходный код CLI приложения
- `test_*.py` — тесты
- `docs/` — документация
